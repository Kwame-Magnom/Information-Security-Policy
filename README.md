# Information Security Policy – Pentecost University

## Project Overview
This project presents an Information Security Policy developed for Pentecost University as part of an academic assignment.

The policy outlines security measures, guidelines, and procedures designed to protect the university's information assets against cyber threats and unauthorized access.

## Objectives
- Protect the confidentiality, integrity, and availability (CIA) of information.
- Identify and manage information security risks.
- Establish security policies and responsibilities.
- Improve cybersecurity awareness.
- Recommend appropriate technical and physical security controls.

## Standards and Legal Frameworks
- ISO/IEC 27001
- ISO/IEC 27002
- NIST Cybersecurity Framework 2.0
- Ghana Data Protection Act, 2012 (Act 843)
- Cybersecurity Act, 2020 (Act 1038)
